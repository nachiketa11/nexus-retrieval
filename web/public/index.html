NEXUS is a retrieval agent for developer code search. It reads your question, plans which tools to use, searches with lexical and semantic retrievers, understands SDK versions and deprecations, follows migration links to the current API, checks its own confidence, and shows every step it took.

03 / How the agent works
ANALYSE

Parses version, migration and deprecation intent, language, SDK family and code identifiers.

PLAN

Chooses tools: BM25, E5 dense, RRF fusion, cross-encoder, version policy, context boost.

ACT

Runs each tool and records inputs, top results and latency.

RESOLVE

Follows deprecation links so a legacy hit surfaces its current replacement and migration path.

REFLECT

Scores confidence from term coverage, retriever agreement, score margin and metadata; refines the query if low.
